# file-organizer-python
📂 Automatizador de Organización de Archivos
Script desarrollado en Python para la gestión inteligente de directorios.

Funcionalidades:

Clasificación automática por extensiones (PDF, Imágenes, Videos, etc.).

Creación dinámica de carpetas según el tipo de archivo.

Código limpio y estructurado para facilitar su mantenimiento.
